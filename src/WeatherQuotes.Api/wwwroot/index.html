How it works

You type a city name and the app fetches real current weather from Open-Meteo — temperature, condition, humidity. It converts those numbers into a short prose description: "A grey autumn day in London. The rain is steady and cold at 8°C."

That prose is turned into a vector embedding using nomic-embed-text running locally via Ollama. An embedding is a list of 768 numbers that encodes the semantic meaning of the text — rainy days and foggy mornings land close together in this space.

Qdrant, a vector database, holds ~27 000 weather-adjacent paragraphs extracted from 44 classic novels. It finds the paragraphs whose embeddings are geometrically closest to the weather query.

A small filter removes obvious mismatches — scorching-sun quotes on a cold day, blizzard quotes under clear skies — and the final quote is drawn from the survivors. Custom weather mode lets you skip the weather API and type any description directly, in English or Russian.
